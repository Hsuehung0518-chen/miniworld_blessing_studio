# MiniWorld Blessing Studio v1.1

## 開啟方式
1. 直接雙擊 `index.html` 本機使用。
2. 點 `📖 操作說明` 進入 `guide.html`。
3. `qa_report.html` 為沙盒實測紀錄。

## GitHub / Netlify
將此資料夾內容上傳到 repository 根目錄即可；`index.html` 為入口。
