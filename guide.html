AI Art Collectible Studio v2.4
全功能操作流程

兩條工作流：⚡ Prompt-only 快速模式／🏺 完整收藏品模式。

⚡ Quick Mode｜最快 4 步

1

在你的 AI 先上傳參考圖

圖片直接交給你慣用的 ChatGPT、Gemini、Midjourney、Ideogram、FLUX/ComfyUI 或其他生圖工具；本 Studio 不需要拿到圖片。

2

回 Studio 選必要參數

選目標 AI、MiniWorld 形式、世界觀、材質、核心元素、作品文字、比例與轉換強度。

3

生成專用快速指令

系統會依目標 AI 套用 Prompt Adapter。它只是調整指令寫法，不代表已連線該 AI。

4

複製回原 AI 生成

確認參考圖仍在原 AI 對話／工作區，再貼上快速指令。這條流程完全不需要 API Key。

🏺 Collector Mode｜收藏級作品

1

定義作品

題名、收藏者／受贈者、祝福、Edition、落款全部可編輯。

2

描述必留元素

填寫參考圖最不能被改掉的 1–8 個元素，例如招福貓、櫻花、富士山、鳥居與金元寶。

3

選藝術藏品語言

12 種模板＋世界觀＋主材質＋銘牌格式＋卷軸／牌匾／水晶蝕刻／浮雕。

4

生成收藏級 Prompt

把完整 Prompt 貼到已載入參考圖的 AI 圖像生成器。

中文字策略

「要求準確繁中」適合文字能力較好的模型；若模型常寫錯字，切換「保留文字牌位置，後製文字」通常最穩；若只要純藝術畫面，選「不要任何文字」。

手機與瀏覽器

Android：建議 Chrome 正式 HTTPS 網址。
iPhone：建議 Safari 正式 HTTPS 網址；不要把聊天附件或 iOS「檔案」App 的 HTML 預覽當成 Safari 真機測試。

正式驗收：首頁切換、Quick Mode、下拉選項、Prompt 生成、複製、完整模式、明暗模式、字體與返回都要可操作。

隱私與 API

✓ Quick Mode 不上傳圖片　✓ 不需要 API Key　✓ 不宣稱已連上任何外部生圖平台

新增｜中英文可編輯 Prompt 預覽

按「生成專用快速指令」後，可切換「繁體中文／English／中英對照」。每個提示詞框都是可直接編輯的 textarea；可自行增刪美學語句、材質、構圖與限制條件。修改後按「複製目前版本」會複製你最後修改的內容；「中英一起複製」會輸出雙語版本；「還原生成內容」可回到本次系統原始生成結果。

中英文是兩份獨立可編輯稿。修改其中一種語言時，系統不會擅自 AI 翻譯覆蓋另一種語言，避免破壞使用者已微調的創作語意。

✨ 美學微調 Chips

生成 Prompt 後可直接點「更夢幻／更寫實／更高級／更東方／更微縮／更溫暖／文字更少」。系統只在目前已編輯的 Prompt 上加入增量指令，不重寫整段內容。

防呆：同一 Chip 不會重複疊加；可按「復原上一步」回到前一版。若在「中英對照」檢視套用，會分別加入對應的中文與英文增量。
