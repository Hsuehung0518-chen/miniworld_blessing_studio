AI Art Collectible Studio v2.5
全功能操作流程

核心：一份 Prompt DNA → 繁中／English → 模型 Adapter → 人工美學微調。

⚡ Quick Mode

1
先在慣用 AI 上傳參考圖
本工具不拿圖片、不需 API Key。
2
選 Prompt DNA
目標 AI、MiniWorld 形式、世界觀、材質、必留元素、文字、比例、轉換強度。
3
生成雙語 Prompt
繁中與英文由同一組結構參數生成，ChatGPT／Copilot／Gemini 等另套模型 Adapter。
4
Semantic Master 同步
若手改中文，按「中文為主稿 → 同步英文」；若手改英文，按「English as master → 同步中文」。No-API 模式不假裝翻譯自由文字，而會把原始主稿完整嵌入對側作為不可違背的 authoritative directive。
5
美學 Chips
更夢幻／更寫實／更高級／更東方／更微縮／更溫暖／文字更少，會同時加到中英文，不覆蓋原稿；支援防重複與復原。
6
複製回原 AI 生成
選目前語言或中英一起複製。

📚 優質 Prompt 標準範例庫

內建 6 組：招福貓／琉璃宮燈、金龍牡丹錦鯉／玉雕仙界、花鯨祝福／玻璃魚缸、威尼斯極光／魚缸水都、福祿雙全／水晶仙界、私人館藏／博物館展示。每組都包含 Model Adapter、MiniWorld、世界觀、材質、核心元素、比例、文字策略、轉換強度與推薦 Chips。

在 Quick Mode 按「☆ 收藏目前配方」可保存自己的標準，最多 20 組，存在瀏覽器 localStorage。

🏺 Collector Mode

輸入作品題名、收藏者／受贈者、祝福、模板、世界觀、材質與銘牌，再生成收藏級 Prompt。收藏者與銘牌均可自由編輯。

手機驗收

Android：Chrome HTTPS。
iPhone：Safari HTTPS；不要用「檔案」App／聊天附件 HTML 預覽代替 Safari 真機測試。

本版自動測試使用 Chromium；Safari User-Agent／viewport 只能做相容守門，實體 iPhone Safari 仍由真機 Acceptance 完成。
